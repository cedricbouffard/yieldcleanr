# Calcul securise de la moyenne

Calcul securise de la moyenne

## Usage

``` r
safe_mean(x, na.rm = TRUE, default = 0)
```

## Arguments

- x:

  Vecteur numerique

- na.rm:

  Supprimer les NA (defaut TRUE)

- default:

  Valeur par defaut si le vecteur est vide (defaut 0)

## Value

Moyenne ou default
