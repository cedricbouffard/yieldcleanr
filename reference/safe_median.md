# Calcul securise de la médiane

Calcul securise de la médiane

## Usage

``` r
safe_median(x, na.rm = TRUE, default = 0)
```

## Arguments

- x:

  Vecteur numerique

- na.rm:

  Supprimer les NA (defaut TRUE)

- default:

  Valeur par defaut si le vecteur est vide (defaut 0)

## Value

Mediane ou default
